# PharmaAd AI

Telegram-бот, который помогает создавать сценарии видеорекламы для фармацевтических препаратов. Бот пошагово собирает информацию о препарате (название, МНН, форма, аудитория, показания), затем с помощью Gemini предлагает несколько стилей рекламы и генерирует по выбранному стилю готовый сценарий со сторибордом.

## Как это работает

1. `/start` — бот запускает диалог и последовательно спрашивает:
   - торговое название препарата
   - МНН (действующее вещество)
   - лекарственную форму
   - целевую аудиторию
   - фармакологическую группу
   - показания и преимущества
2. На основе собранных данных Gemini предлагает 4 стиля видеорекламы с оценкой и обоснованием.
3. После выбора стиля бот генерирует полный сценарий: слоган, сториборд по сценам, текст озвучки и призыв к действию.
4. `/cancel` — отменить текущий диалог в любой момент.

## Установка

```bash
pip install -r requirements.txt
```

Требуется Python 3.11 (см. `runtime.txt`).

## Переменные окружения

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота, полученный у [@BotFather](https://t.me/BotFather) |
| `GEMINI_API_KEY` | API-ключ Google Gemini |
| `PORT` | Порт для webhook-сервера (по умолчанию `10000`) |
| `RENDER_EXTERNAL_URL` | Публичный URL сервиса — используется для настройки Telegram webhook |

## Запуск

Бот работает в режиме webhook и рассчитан на деплой как веб-сервис (например, на Render). Если `RENDER_EXTERNAL_URL` не задан, бот выведет предупреждение — для локального запуска через long polling потребуется заменить `run_webhook()` на `run_polling()` в `bot.py`.

```bash
python bot.py
```

## Деплой

В репозитории есть `railway.toml` для деплоя на Railway (сборка через Nixpacks, старт командой `python bot.py`).
