# PharmaAd AI

Telegram-бот, который помогает создавать сценарии видеорекламы для фармацевтических препаратов. Бот пошагово собирает информацию о препарате (название, МНН, форма, аудитория, показания), затем с помощью Gemini предлагает несколько стилей рекламы, генерирует по выбранному стилю готовый сценарий со сторибордом и по кнопке собирает готовый видеоролик — бесплатно, без платных видео-API.

## Как это работает

1. `/start` — бот запускает диалог и последовательно спрашивает:
   - торговое название препарата
   - МНН (действующее вещество)
   - лекарственную форму
   - целевую аудиторию
   - фармакологическую группу
   - показания и преимущества
2. На основе собранных данных Gemini предлагает 4 стиля видеорекламы с оценкой и обоснованием.
3. После выбора стиля бот генерирует полный сценарий: слоган, сториборд по сценам (включая ключевые слова для подбора видеоряда), текст озвучки и призыв к действию.
4. По кнопке «🎬 Сгенерировать видео» бот спрашивает фото упаковки препарата (можно пропустить), затем на каждую сцену: озвучивает текст через EdgeTTS (бесплатно, без ключа), подбирает подходящий стоковый видеоряд через Pexels API (бесплатный ключ), подмешивает фоновую музыку (`assets/bg_music.mp3`, CC0) и накладывает текст сцены поверх через FFmpeg. Сцены склеиваются в один вертикальный ролик (9:16) с финальной карточкой бренда, CTA и (если прислано) фото упаковки. Генерация занимает 1–3 минуты, видео присылается в чат как черновик, требующий юридической проверки перед публикацией.
5. `/cancel` — отменить текущий диалог в любой момент.

## Стоимость видео

$0. Видео не генерируется нейросетью с нуля — оно собирается из бесплатных компонентов: EdgeTTS (озвучка, ключ не нужен), Pexels (стоковый видеоряд, бесплатный API-ключ с щедрой квотой) и FFmpeg (склейка/субтитры, локально). Из-за этого в ролике — реальные стоковые кадры по смыслу сцены, а не сгенерированные кадры конкретного препарата/упаковки.

## Установка

```bash
pip install -r requirements.txt
```

Требуется Python 3.11 (на Render версия фиксируется файлом `.python-version`, на Railway/Heroku-style платформах — `runtime.txt`; Render `runtime.txt` игнорирует), а также системные пакеты `ffmpeg` и `ffprobe` (на Render ставятся автоматически из `apt.txt`; на Railway — через `nixpacks.toml`; локально — `apt install ffmpeg` / `choco install ffmpeg` / `brew install ffmpeg`). Шрифт с поддержкой кириллицы для субтитров лежит в `assets/DejaVuSans-Bold.ttf`.

> ⚠️ Без `.python-version` Render подставляет последний доступный Python (сейчас 3.14), а C-расширение `protobuf` (зависимость `google-genai`) на нём падает с `TypeError: Metaclasses with custom tp_new are not supported`. Файл `.python-version` в репозитории это фиксирует — не удалять.

## Переменные окружения

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота, полученный у [@BotFather](https://t.me/BotFather) |
| `GEMINI_API_KEY` | API-ключ Google Gemini |
| `PEXELS_API_KEY` | Бесплатный API-ключ [Pexels](https://www.pexels.com/api/) для подбора видеоряда |
| `PORT` | Порт для webhook-сервера (по умолчанию `10000`, на Render подставляется автоматически) |
| `RENDER_EXTERNAL_URL` | Публичный URL сервиса — используется для настройки Telegram webhook (на Render подставляется автоматически) |

## Запуск

Бот работает в режиме webhook — нужен публичный URL. Подходит для бесплатного тарифа **Web Service** на Render. Из-за бесплатного тарифа сервис засыпает после ~15 минут простоя и просыпается с задержкой на первое сообщение после паузы — это ожидаемое поведение, а не баг.

```bash
python bot.py
```

Для локального запуска (или на платформе без публичного URL) замените в `bot.py` вызов `app.run_webhook(...)` на `app.run_polling()`.

## Деплой

- **Render** — создать сервис типа **Web Service** (не Background Worker — там нет бесплатного тарифа), build command `pip install -r requirements.txt`, start command `python bot.py`. `PORT` и `RENDER_EXTERNAL_URL` Render проставляет сам, системные пакеты — из `apt.txt`. Вручную указать только `BOT_TOKEN`, `GEMINI_API_KEY`, `PEXELS_API_KEY`.
- **Railway** — в репозитории есть `railway.toml` (сборка через Nixpacks с `ffmpeg`, старт командой `python bot.py`).

## Генерация видео из чата (без Telegram)

Весь пайплайн сборки ролика (промпты Gemini, EdgeTTS, Pexels, FFmpeg) вынесен из `bot.py` в переиспользуемый модуль `video_pipeline.py`. В `.claude/skills/pharma-video-generation/` лежит Claude Code Skill, который позволяет сгенерировать черновик видеорекламы препарата прямо из чата с Claude, без запуска Telegram-бота:

```bash
python .claude/skills/pharma-video-generation/scripts/generate_ad_video.py \
  --brand "Название" --inn "МНН" --form "Форма" \
  --audience "Аудитория" --group "Группа" --indications "Показания" \
  --output /tmp/ad.mp4
```

Нужны те же `GEMINI_API_KEY`/`PEXELS_API_KEY` и системные `ffmpeg`/`ffprobe`, что и для бота.
