# Генерация видеорекламы препарата из чата

Этот скилл прогоняет тот же пайплайн, что и Telegram-бот (`bot.py`), но
напрямую из чата, без Telegram: собери данные о препарате в разговоре,
запусти CLI-скрипт и отдай пользователю готовый ролик.

## Когда применять

Пользователь просит сгенерировать/собрать видеорекламу, промо-ролик,
рекламный видеосценарий с видео для конкретного (или вымышленного тестового)
препарата. Не путай с обычным вопросом "как работает бот" — в таком случае
достаточно объяснить, скилл не нужен.

## Шаг 1 — собери данные о препарате

Пайплайну нужны те же 6 полей, что бот запрашивает по шагам в `bot.py`:

| Поле | Что это | Пример |
|---|---|---|
| `brand` | Торговое название | Ринзасип |
| `inn` | МНН (действующее вещество) | парацетамол + фенирамин + аскорбиновая кислота |
| `form` | Лекарственная форма | Порошок для приготовления раствора |
| `audience` | Целевая аудитория | Взрослые (18+) |
| `group` | Фармакологическая группа | Средство от простуды и гриппа |
| `indications` | Показания и преимущества (2-3 предложения) | Снимает температуру, боль, заложенность носа |

Если пользователь дал не всё сразу — спроси недостающее одним сообщением,
не растягивай на пошаговый диалог, как это делает бот (в чате это избыточно).
Если пользователь просто просит "сгенерируй тестовое видео для примера" без
конкретного препарата — придумай правдоподобный тестовый пример сам и скажи
об этом пользователю, вместо того чтобы засыпать его вопросами.

## Шаг 2 — проверь окружение

Скрипту нужны переменные окружения `GEMINI_API_KEY` и `PEXELS_API_KEY`
(те же, что описаны в README проекта), а также системные `ffmpeg`/`ffprobe`
в PATH. Если одна из переменных не задана, скрипт сразу упадёт с понятной
ошибкой в stderr — сообщи об этом пользователю и попроси задать переменную,
не пытайся угадывать или подставлять фиктивный ключ.

## Шаг 3 — запусти генерацию

```bash
python .claude/skills/pharma-video-generation/scripts/generate_ad_video.py \
  --brand "<название>" \
  --inn "<МНН>" \
  --form "<форма>" \
  --audience "<аудитория>" \
  --group "<группа>" \
  --indications "<показания>" \
  --output /tmp/ad.mp4
```

Скрипт сам вызывает Gemini для стилей и сценария, затем собирает видео —
это может занять 1-3 минуты (сеть + FFmpeg), предупреди об этом пользователя
перед запуском. По умолчанию (без `--style`) выбирается стиль с наивысшим
`score` от Gemini; передай `--style N` (индекс 0-3), если пользователь явно
выбрал конкретный стиль из предложенных. Опционально `--photo <путь>`
добавляет фото упаковки в финальную карточку ролика.

При успехе скрипт печатает в stdout один JSON-объект вида
`{"video_path": "...", "style": {...}, "script": {...}}` — из него видно
путь к готовому mp4, выбранный стиль и полный сценарий (слоган, сцены,
CTA). При ошибке (например, Pexels не нашёл видео по ключевым словам сцены,
или Gemini вернул невалидный JSON) скрипт завершится с ненулевым кодом и
сообщением в stderr — покажи его пользователю как есть, не скрывай детали.

## Шаг 4 — отдай результат пользователю

Отправь получившийся mp4-файл пользователю (например, инструментом отправки
файлов, если он доступен в этой среде) и кратко перескажи сценарий: слоган,
количество сцен, CTA. Обязательно напомни, что это черновик на стоковых
кадрах Pexels для внутренней оценки — как и в самом боте, ролик требует
юридической проверки перед публикацией (никаких реальных кадров конкретной
упаковки препарата в видео нет, если не передано `--photo`).

## Важно: не дублируй логику

Вся логика пайплайна (промпты к Gemini, TTS, работа с Pexels, сборка через
FFmpeg) живёт в `video_pipeline.py` в корне репозитория — её же использует
`bot.py`. Не копируй эту логику в новый код и не переписывай её заново:
CLI-скрипт `scripts/generate_ad_video.py` уже импортирует нужные функции
(`generate_styles`, `generate_script`, `assemble_video_sync`). Если чего-то
не хватает (например, нужен новый параметр), правь `video_pipeline.py`
и пробрасывай новый аргумент через CLI-скрипт, а не форкай пайплайн.
